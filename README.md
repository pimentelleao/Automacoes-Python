---

## 🎯 Objetivo

Demonstrar uma solução de **automação de processos (RPA)** voltada à redução de atividades repetitivas, ao tratamento de exceções e à rastreabilidade de operações.

O projeto reúne rotinas para identificar solicitações, interpretar dados, executar verificações, organizar documentos e registrar os resultados de cada etapa.

## 🔄 Fluxo do processo

1. **Identificação:** leitura de solicitações e identificação do tipo de atividade.
2. **Extração:** obtenção de dados em descrições e planilhas Excel.
3. **Validação:** conferência de informações, documentos e regras de consistência.
4. **Processamento:** navegação automatizada em interfaces web e ERP.
5. **Documentos:** organização de arquivos e verificação de anexos.
6. **Monitoramento:** geração de logs, tratamento de falhas e retomada controlada.

## ⚙️ Principais funcionalidades

- Automação de navegação web com **Playwright**.
- Leitura e tratamento de planilhas com **Pandas**.
- Extração de identificadores a partir de dados estruturados e texto.
- Validações cruzadas e prevenção de processamento duplicado.
- Organização de documentos e arquivos de saída.
- Registro de eventos, resultados e erros para auditoria técnica.
- Recuperação de fluxos interrompidos e tratamento de exceções.
